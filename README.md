# 🧭 ไกด์ท่องเที่ยวจังหวัดปราจีนบุรี (RAG Chatbot)

แชตบอตตอบคำถามเรื่องท่องเที่ยวปราจีนบุรี (ธรรมชาติ ผจญภัย โบราณสถาน อาหาร การเดินทาง) ด้วยเทคนิค RAG
ตอบจากเอกสารในโฟลเดอร์ `data/` เท่านั้น แสดงแหล่งอ้างอิงทุกครั้ง และตอบ "ไม่พบข้อมูลในเอกสาร" เมื่อเอกสารไม่มีคำตอบ

- **URL เว็บ Streamlit:** (ใส่ลิงก์หลัง deploy)
- **GitHub:** https://github.com/Loltete/test2

## แนวคิดของ Domain
ปราจีนบุรีเป็นจังหวัดใกล้กรุงเทพฯ ที่มีทั้งผืนป่ามรดกโลก กิจกรรมล่องแก่ง และเมืองโบราณสมัยทวารวดี
แต่ข้อมูลกระจัดกระจาย แชตบอตนี้รวมข้อมูลไว้ที่เดียว ให้ถามเป็นภาษาธรรมชาติและตรวจสอบที่มาได้

## เทคนิคที่ใช้
| ขั้นตอน | รายละเอียด |
|---|---|
| Loading & Chunking | อ่านไฟล์ `.txt` ใน `data/` ทำความสะอาดช่องว่าง ตัดประโยคด้วย PyThaiNLP (`crfcut`) แล้วรวมเป็น chunk ราว 500 ตัวอักษร ซ้อนทับ 100 ตัวอักษร |
| Embedding | `paraphrase-multilingual-MiniLM-L12-v2` (รองรับไทย/อังกฤษ ขนาดเล็ก) |
| Vector Search | FAISS `IndexFlatIP` บนเวกเตอร์ที่ normalize แล้ว (cosine), top-k = 4, กรองด้วย score ขั้นต่ำ |
| Prompt | system prompt บังคับตอบจากบริบทเท่านั้น อ้างอิง `[ไฟล์#chunk]` และตอบ "ไม่พบข้อมูลในเอกสาร" เมื่อไม่มีคำตอบ |
| LLM | Groq API (`llama-3.3-70b-versatile`) |
| Interface | Streamlit chat เก็บประวัติสนทนา และมี expander แสดงเอกสารอ้างอิงทุกคำตอบ |

## วิธีรันในเครื่อง
```bash
pip install -r requirements.txt
mkdir .streamlit
# สร้างไฟล์ .streamlit/secrets.toml แล้วใส่  GROQ_API_KEY = "คีย์ของคุณ"
streamlit run app.py
```
ห้าม commit `.streamlit/secrets.toml` (อยู่ใน `.gitignore` แล้ว) เมื่อ deploy ให้ใส่คีย์ที่ Settings > Secrets ของ Streamlit Community Cloud

## แหล่งที่มาของเอกสาร
เอกสารใน `data/` เรียบเรียงขึ้นใหม่ด้วยถ้อยคำของผู้จัดทำ โดยอ้างอิงข้อมูลสาธารณะและช่วยร่างด้วย AI จากแหล่งดังนี้
- Wongnai Trips / Wongnai Listings (ที่เที่ยวและร้านอาหารปราจีนบุรี)
- TrueID Travel (อุทยานแห่งชาติทับลาน ประวัติเมืองโบราณศรีมโหสถ)
- GotoKnow (ผืนป่าตะวันออก อุทยานแห่งชาติปางสีดา)
- นิตยสารศิลปวัฒนธรรม (เมืองมโหสถ สระแก้ว ประวัติเมืองปราจีนบุรี)
- คู่มือการออกแบบอาคารในเขตคุ้มครองเมืองโบราณศรีมโหสถ (สำนักงานนโยบายและแผนทรัพยากรธรรมชาติและสิ่งแวดล้อม)

> ข้อมูลราคา ช่วงเวลา และการเปิดให้บริการอาจเปลี่ยนแปลง ควรตรวจสอบกับผู้ให้บริการก่อนเดินทาง

## ไฟล์ทดสอบ
`test_questions.csv` มี 13 ข้อ (10 ข้อมีคำตอบ รวม 1 ข้อภาษาอังกฤษ และ 3 ข้อไม่มีในเอกสาร)

## ตัวอย่าง Prompt ที่ใช้สั่ง AI ช่วยเขียนโค้ด
1. "ช่วยสร้าง Streamlit RAG chatbot ภาษาไทย/อังกฤษ ใช้ sentence-transformers + FAISS + Groq โหลดโมเดลครั้งเดียวด้วย st.cache_resource แสดงเอกสารอ้างอิงทุกคำตอบ"
2. "เขียน system prompt ให้ LLM ตอบจากบริบทเท่านั้น อ้างอิงแหล่งที่มา และตอบว่าไม่พบข้อมูลเมื่อไม่มีในเอกสาร"
3. "ช่วยเรียบเรียงเอกสารท่องเที่ยวปราจีนบุรีจากข้อมูลที่ค้นได้ เป็นไฟล์ข้อความภาษาไทยหลายไฟล์ สำหรับใช้เป็นคลังความรู้ RAG"
